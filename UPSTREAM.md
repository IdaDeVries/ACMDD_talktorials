# Upstream provenance

This repository contains the the course materials for ACMDD (Advanced Computational Methods in Drug Discovery), a MSc course at Leiden University. The material is based on selected TeachOpenCADD talktorials.

## Course-specific modifications

Compared to the upstream TeachOpenCADD project, this repository:

- Is independend of teachopencadd (utils) 
- Uses updated API calls
- Contains updated MD simulation talktorials
- Has been restructured for ACMDD course usage
- Contains only the talktorials used within ACMDD
- Is tested for use on Noteable AY2627
